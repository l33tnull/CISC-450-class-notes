# Database Basics
## Data

-  is numeric, textual, visual, or audio info
- describes real-world systems
- collected and processed to aid tasks 
	- Ex: forecasting weather, analyzing financial investments, or tracking global spread pandemics
## Ways Data Varies:

- *Scope:* amount of data produced; collected 
	- Ex: small business track inventory of thousand items but commerce site tracks billions
- *Format:* produced as numbers, text. image, audio, video 
	- Ex: phones proximity sensor generates raw numbers; satellite captures images
- *Access:* some data sources private; others public 
	- Ex: retail company use private customer data for purchasing behavior; government required to share certain data sets
## Database

A collection of data in structured format
### Database Software

Database Software is organized in layers:
		1. Applications interact with query language
		2. Query language interacts with database system

### Database Software Tools

- *Database System or Database Management System (DBMS):*  
	- Software that reads and writes data in database 
	- Ensures data is secure, internally consistent, and available
	- Complex for large databases with many users
	- handles all access control including checking creds, enforcing permissions, and deciding which queries are allowed
- *Query:*
	- Request to retrieve or change data in database
- *Query Language:* 
	- Is programming language for database systems
	- Read and write data efficiently
	- Differ from Python, Java, and C++
- *Database Application:*
	- Software that helps business users interact with database systems
	- Programmers write applications to simplify the user experience and ensure data access is secure and efficient cause many systems are complex
### Database Roles

- *Database Admin:*
	- Responsible for securing database system against unauthorized users
	- Enforces procedures for user access and system availability
- *Database Designer:*
	- Determines format of each data element; overall database structure
	- Must balance priorities; storage; response time; support for rules that govern data
	- Design technically challenging cause priorities conflict
- *Database Programmer:*
	- Develops computer programs that utilize database
	- Write applications that combine query language and general-purpose programming languages
	- Since query and general languages have differences, database programming is challenge
- *Database User:*
	- Consumer of data in database
	- Request, update, use stored data to generate reports of info
	- Usually access database via apps
	- Can also submit queries directly to the database system

- For simple databases with a limited amount of data and few users, one person may assume several roles. 
	- Ex: The database administrator might also be a database designer or database programmer. For large, complex databases, each person usually takes on just one role.
