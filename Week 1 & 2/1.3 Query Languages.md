# What is Structured Query Language (SQL)

- the standard query language of relational database systems
- sponsored by the American National Standards Institute (ANSI) and the International Organization for Standardization (ISO)
- first developed at IBM in 1970s as experimental query language for prototype relational database
# Writing Queries with SQL
### Terminology

- *SQL Statement:* database command, such as a query that inserts, selects, updates, or deletes data
		- `INSERT` inserts rows into a table
		- `SELECT` retrieves data from a table
		- `UPDATE` modifies data in a table
		- `DELETE` deletes rows from a table

# Creating Tables with SQL

- *SQL CREATE TABLE*: 
		- statement that creates a new table by specifying the table and column names
		- each column is assigned a data type that indicates the format of column values
		- data types can be numeric, textual, or complex
			- `INT` stores integer values
			- `DECIMAL` stores fractional numeric values
			- `VARCHAR` stores textual values
			- `DATE` stores year, month, and day
		- some data types are followed by one or two numbers in parenthesis indicating the size of the data type
			- `VARCHAR(10)` indicates ten characters
			- `DECIMAL(10, 3)` indicates ten significant digits including three after the decimal point
		- only put a trailing comma if there is another column definition not before the closing parenthesis

# Inserting, Updating, and Deleting Rows

## `INSERT` Statement

- adds rows to table
- has two clauses
		- `INSERT INTO` names the table and columns where data is to be added; keyword `INTO` is optional
		- `VALUES` specifies the column values to be added
			- `VALUES` may list any number of rows in parenthesis to insert multiple rows
- if you leave out the column list after `TableName` the values after `VALUES` must match the order given in the `CREATE TABLE` statement

<u>Figure  1: INSERT syntax</u>
```
INSERT [INTO] TableName (Column1, Column2, ...)
VALUES (Value1, Value2, ...);
```
![[Pasted image 20260829114437.png]]

## `DEFAULT` Values

Columns may be omitted from an INSERT statement. When omitted, a column is assigned a NULL value. If the NOT NULL constraint is specified on the column, the insert is rejected.

Alternatively, a default value may be specified for a column. The optional DEFAULT keyword and default value follow the column name and data type in a CREATE TABLE statement. The column is assigned the default value, rather than NULL, when omitted from an INSERT statement.

![[Pasted image 20260829120943.png]]

## `UPDATE` Statement

- modifies existing rows in table
- uses the `SET` clause to specify the new column values
- `WHERE` clause specifies which rows are updated
- omitting `WHERE` clause results in all rows being updated

<u>Figure 2 : UPDATE syntax</u>
```
UPDATE TableName
SET Column1 = Value1, Column2 = Value2, ...
WHERE condition;
```
![[Pasted image 20260829121415.png]]

## `DELETE` Statement

- deletes existing rows in table
- `FROM` keyword is followed by table name whose rows are to be deleted
- `WHERE` clause specifies which rows should be deleted
- omitting `WHERE` clause results in all rows in table being deleted

<u>Figure 2.8.3: DELETE syntax</u>
```
DELETE FROM TableName 
WHERE condition;
```
